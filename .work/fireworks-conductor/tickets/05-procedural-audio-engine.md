# Ticket 05: Procedural Web Audio Pyrotechnics Engine

## Intent
Build a zero-dependency, low-latency procedural sound synthesizer using the Web Audio API to create authentic pyrotechnic sound design: ascending whistles, punchy explosion thuds, fountain sizzles, sparkler crackles, and spinner whirs.

## Acceptance Criteria
- [ ] Zero external audio files (no broken links, instant startup).
- [ ] AudioContext initialization on first user gesture / click.
- [ ] Rocket sound: ascending pitch sweep ($300\text{Hz} \to 1800\text{Hz}$) with envelope + explosive low-frequency thud upon burst.
- [ ] Anar sound: continuous bubbling sizzle and crackle loop while fist is held.
- [ ] Starburst sound: sharp initial pop followed by deep sub-bass boom and shimmering crackle decay.
- [ ] Roman Candle: crisp rhythmic "fwoomp" pops.
- [ ] Sparkler sound: granular micro-impulse crackles modulated by hand speed.
- [ ] Chakri sound: resonant frequency-modulated whir.
- [ ] Pitch and timbre randomization (±8%) so repeated triggers sound alive.
- [ ] Mute / volume toggle in HUD.
