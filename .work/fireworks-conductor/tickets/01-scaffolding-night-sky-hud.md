# Ticket 01: Scaffolding, Night Sky Video Feed & Creator HUD

## Intent
Set up Vite + TypeScript project structure, full-window responsive viewport, mirrored webcam video feed with night-sky atmosphere grading (darkened vignette, subtle deep indigo tint), gesture reference bar, status pill, and Creator Mode (`H` hotkey) to toggle HUD for reel recording.

## Acceptance Criteria
- [ ] Vite + TypeScript project scaffolded and builds cleanly.
- [ ] Responsive full-screen canvas layout with webcam feed stream initialized at 640x480.
- [ ] Night-sky video filter applied (dimmed to ~40-45% so fireworks pop with maximum contrast).
- [ ] Gesture reference legend at bottom showing the 7 gestures.
- [ ] Creator Mode toggle (key `H` or HUD button) to hide all UI elements for clean recording.
- [ ] Status indicator showing camera / tracking readiness.
